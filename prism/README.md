# 🏛️ PRISM Web Application — Predictive Risk Intelligence for Smart Monitoring

This directory contains the Next.js 16 (Turbopack) web application for **PRISM**, built for **Smart India Hackathon 2026** under the **Ministry of Statistics and Programme Implementation (MoSPI)**.

For the full architectural documentation, empirical ML benchmarks, and methodology, see the [Root Repository README](../README.md).

---

## ⚡ Quickstart

```bash
# Install dependencies
npm install

# Run the local Turbopack development server
npm run dev
```

Visit:
- **Landing Page**: [http://localhost:3000](http://localhost:3000)
- **iPRISM AI Intelligence Portal**: [http://localhost:3000/iprism](http://localhost:3000/iprism)
- **Command Center Dashboard**: [http://localhost:3000/dashboard](http://localhost:3000/dashboard)

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16.3.6 (App Router with Turbopack)
- **Language**: TypeScript 5.0 (Strict mode)
- **Styling**: Vanilla CSS Design System with high-contrast accessibility tokens
- **Intelligence**: iPRISM Machine Learning diagnostics (90.0% LOOCV Accuracy)
- **Data Source**: PAIMANA Infrastructure Dataset (`../paimana_real_sample.csv`)
